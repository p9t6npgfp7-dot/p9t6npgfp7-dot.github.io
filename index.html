Jesse Liao Release Tool

A private publishing tool for the musician Jesse Liao. Uses YouTube API Services and the Meta Graph API.

About

Jesse Liao is an independent musician. This tool runs only on Jesse Liao's own computer and is used to publish Jesse Liao's original songs to the YouTube channel Jesse Liao and, when the owner connects them, to Jesse Liao's Facebook Page and Instagram professional account. For each release it uploads the finished video and sets its title, description, thumbnail or cover, visibility and publish time. Nothing is uploaded until Jesse Liao has reviewed and approved that release. The tool is not offered to anyone else.

Privacy Policy

Last updated: November 25, 2026.

  • YouTube API Services. This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • What is accessed: Google. With the owner's consent (Google OAuth, scope youtube.force-ssl), the tool reads the authorized channel's ID and title, uploads videos the owner approved, sets their title, description, tags, category, language, thumbnail, visibility, scheduled publish time, made-for-kids setting and altered or synthetic content disclosure, and reads back their processing and privacy status. It does not delete videos.
  • What is accessed: Meta (only after the owner connects Facebook or Instagram). With the owner's consent (Facebook Login, permissions pages_show_list, pages_read_engagement, pages_manage_posts, instagram_basic, instagram_content_publish), the tool reads the ID and name of the owner's Page and of the Instagram professional account linked to it, uploads Reels the owner approved with their caption, cover and publish time, and reads back their status and links. If the owner cancels a scheduled Facebook Reel before it goes live, the tool deletes that unpublished Reel. Meta's handling of data is described in the Meta Privacy Policy.
  • What is stored, and where. The tool keeps its data on the owner's computer, in its local database and log files:
    • Encrypted with Windows DPAPI, so that only the owner's Windows user account on that computer can decrypt them: the platforms' app credentials (client IDs and secrets), access and refresh tokens, the email address of the Google account used to sign in, sign-in requests in progress, and upload progress records.
    • Stored without that extra encryption, protected by the computer's own account security: the connected accounts' names, IDs, granted permissions and connection status; release plans (titles, descriptions, tags, visibility, AI-content disclosure and scheduled times); approvals and review history; the location and SHA-256 fingerprint of each media file, and an unchanged copy of each approved video and cover kept for uploading; the IDs, links and status of uploaded videos and Reels; and activity logs.
  • Where data goes. To publish and to check releases, the tool connects to the platforms' own servers: Google for YouTube, and Meta for Facebook and Instagram. Its local interface also loads a typeface from Google Fonts, which, like any web request, receives the computer's IP address. It contains no analytics, advertising or third-party tracking code. It does not sell data, and it sends account and release data only to the platform it is publishing to.
  • Revoking access. Access can be revoked at any time at Google Account permissions and in Facebook settings → Business integrations. Revoked tokens stop working; the tool then marks that connection as needing re-authorization and does not publish to it until it is connected again. The tool's own "disconnect" setting only stops it from using a connection; it does not revoke access at the platform and does not delete the stored token.
  • Deleting data. Stored tokens and records are deleted by deleting the tool's data folder on the owner's computer. Videos and Reels already published stay on the platforms until they are deleted there. For Facebook and Instagram, see Data Deletion.
  • This website. This page is hosted on GitHub Pages. GitHub may record visitors' IP addresses as described in the GitHub Privacy Statement.
  • Contact. Privacy questions and deletion requests: jesseliao.music@gmail.com.
